CodeRyse Academy — Resumo do Projeto
======================================


1. VISÃO GERAL
--------------

O CodeRyse Academy é um protótipo de frontend de uma plataforma de ensino a distância
desenvolvido como projeto integrador do 3.º semestre (PIM3). O sistema simula um ambiente
acadêmico digital completo com quatro perfis de acesso — Aluno, Professor, Coordenador e
Administrador — cada um com painel e funcionalidades próprias.

Objetivo: demonstrar, em protótipo de alta fidelidade, os fluxos e a experiência de uso
de uma plataforma EAD acadêmica, sem necessidade de infraestrutura de servidor.


2. IMPORTÂNCIA DO PROTÓTIPO DE FRONTEND NO PROJETO
------------------------------------------------

Em um projeto de desenvolvimento de sistema, a interface com o usuário é o ponto de
contato direto entre a solução proposta e quem irá utilizá-la. O protótipo de frontend
do CodeRyse Academy cumpre um papel central na validação do projeto como um todo: ele
materializa, de forma visual e interativa, todas as decisões tomadas nas demais
disciplinas do semestre — modelagem de banco de dados, análise de sistemas, regras de
negócio e requisitos funcionais.

Sem uma interface funcional, os diagramas, modelos e especificações permanecem abstratos.
O protótipo transforma essas definições em fluxos navegáveis, tornando possível avaliar
se a arquitetura proposta atende às necessidades reais dos perfis de usuário, identificar
inconsistências nos requisitos e comunicar a solução de forma clara para qualquer
avaliador, independentemente de conhecimento técnico.

Nesse contexto, o frontend não é apenas a "camada visual" do projeto — é a síntese
prática de todo o trabalho integrado do semestre.


3. FERRAMENTAS E TECNOLOGIAS UTILIZADAS
----------------------------------------

Desenvolvimento

- React              Biblioteca para construção da interface, responsável por toda a
                     estrutura de telas e componentes.

- Vite               Ferramenta de desenvolvimento e empacotamento do projeto, garante
                     servidor local rápido e geração do build final.

- React Router DOM   Gerenciamento de navegação entre as páginas da aplicação.

- Framer Motion      Biblioteca de animações para transições e efeitos visuais
                     nos componentes.

- Recharts           Geração de gráficos e visualizações de dados nos dashboards.

- React Icons        Conjunto de ícones utilizado em toda a interface.

- CSS Puro           Estilização completa sem frameworks externos, com sistema de
                     variáveis próprio para cores, espaçamentos e tipografia.

Infraestrutura e Organização

- Git                Controle de versão do código ao longo do desenvolvimento.

- GitHub             Repositório remoto para armazenamento e histórico do projeto.

- Google Fonts       Fontes Inter e Outfit utilizadas no design system da plataforma.

- localStorage       Armazenamento de dados no navegador para simular persistência
                     sem banco de dados real.

- vite-plugin-html   Plugin que permite organizar partes do HTML em arquivos separados,
                     mantendo o projeto mais organizado.


4. DETALHAMENTO DO PROTÓTIPO
-----------------------------

O protótipo foi desenvolvido para simular, de forma fiel, o funcionamento de uma
plataforma de ensino a distância. A ideia central é que qualquer pessoa — aluno,
professor, coordenador ou administrador — consiga acessar o sistema e encontrar
exatamente o que precisa, de acordo com o seu perfil.

Página inicial

A experiência começa pela página inicial, onde visitantes podem conhecer os cursos
disponíveis, ver preços e níveis de dificuldade, e solicitar uma matrícula. A plataforma
conta com seis cursos cadastrados — Desenvolvimento Web, Inteligência Artificial,
Ciência de Dados, Cybersegurança, UX e UI Design, e Robótica.

Painéis por perfil

Após o login, cada tipo de usuário acessa um painel personalizado:

- Aluno          Acompanha seu progresso, acessa os conteúdos das aulas, realiza
                 avaliações e pode emitir certificados ao concluir um curso.

- Professor      Visualiza suas turmas e o desempenho dos alunos por módulo.

- Coordenador    Gerencia cursos, matrículas e a equipe de professores.

- Administrador  Tem visão completa da plataforma e controle total sobre os usuários.

Abrangência

Ao todo, o sistema conta com 23 telas funcionais e navegação completa entre todas as
áreas. Os fluxos foram pensados para refletir situações reais: um aluno não consegue
acessar áreas administrativas, uma turma não pode ser criada sem um curso vinculado,
uma matrícula passa por aprovação antes de liberar o acesso ao conteúdo.

A interface funciona em computadores e dispositivos móveis, com navegação adaptada para
telas menores. É possível também salvar a página inicial como PDF pelo próprio navegador,
sem nenhuma etapa adicional.


5. O PAPEL DO HTML, JAVASCRIPT E JSX NO PROJETO
-------------------------------------------------

HTML

É a base estrutural de qualquer página web. No projeto, o HTML aparece principalmente
em um único arquivo que serve como ponto de entrada da aplicação — é ele que o navegador
carrega primeiro. Também é usado diretamente na seção de impressão da página inicial,
onde o conteúdo precisa existir de forma estática para funcionar com o Ctrl+P.

JavaScript

É a linguagem de programação que dá vida à interface. No projeto, o JavaScript é
responsável por toda a lógica da aplicação: controlar qual tela o usuário vê, verificar
se ele está logado, filtrar dados, calcular progresso, gerenciar o estado dos formulários
e conectar as ações do usuário com as respostas da interface.

JSX (JavaScript XML)

É uma extensão do JavaScript criada pelo React que permite escrever a estrutura visual
das telas dentro do próprio código. Na prática, é uma mistura de HTML com JavaScript —
em vez de separar a estrutura da lógica em arquivos diferentes, o JSX mantém os dois
juntos no mesmo componente. Cada tela do projeto é escrita em JSX, o que facilita
reutilizar partes da interface e manter tudo organizado por funcionalidade.

Em resumo: o HTML define a estrutura inicial da página, o JavaScript controla o
comportamento e a lógica, e o JSX une os dois dentro do React para construir as telas
de forma organizada e reutilizável.


6. FUNCIONALIDADES IMPLEMENTADAS
----------------------------------

- Página pública com catálogo de cursos e fluxo de matrícula
- Autenticação simulada com controle de acesso por perfil
- Dashboards individuais por perfil com estatísticas e indicadores
- Gestão completa de cursos, módulos, turmas, matrículas e avaliações
- Acompanhamento de progresso e conteúdos por aluno
- Quiz interativo com pontuação e feedback imediato
- Emissão de certificados por curso concluído
- Impressão nativa da página inicial via Ctrl+P (salvar como PDF)
- Interface responsiva com sidebar colapsável para dispositivos móveis
- Tema dark com design system padronizado
